# 📋 แม่แบบข้อมูลเรซูเม่ (Resume Data Templates)

คัดลอกและวางข้อมูลเหล่านี้ลงในไฟล์ `master-cv-th.json` ของคุณ

⚠️ **สำคัญ**: อย่าลืมใส่เครื่องหมายจุลภาค (`,`) ระหว่างรายการหากคุณเพิ่มมากกว่าหนึ่งรายการ!

---

### 💼 ประสบการณ์การทำงาน (Work Experience)
วางสิ่งนี้ลงในรายการ `"experience": [`:

```json
{
    "company": "ชื่อบริษัท",
    "role": "ตำแหน่งงานของคุณ",
    "startDate": "เดือน ปี (เช่น พฤษภาคม 2567)",
    "endDate": "เดือน ปี หรือ ปัจจุบัน",
    "highlights": [
        { "text": "อธิบายหน้าที่ความรับผิดชอบหรือผลงานสำคัญที่นี่", "tags": ["technical", "management"] },
        { "text": "อธิบายรายละเอียดงานเพิ่มเติมที่นี่", "tags": ["creative"] }
    ]
}
```

---

### 🎓 การศึกษา (Education)
วางสิ่งนี้ลงในรายการ `"education": [`:

```json
{
    "institution": "ชื่อมหาวิทยาลัยหรือสถานศึกษา",
    "area": "คณะ/สาขาวิชา (เช่น ศิลปศาสตรบัณฑิต สาขาวิชาภาษาอังกฤษ (2563-2567))",
    "tags": ["education"]
}
```

---

### 🛠️ ทักษะ (Skill)
วางสิ่งนี้ลงในรายการ `"skills": [`:

```json
{
    "name": "ชื่อทักษะ (เช่น JavaScript, การพูดในที่สาธารณะ)",
    "tags": ["technical", "business"]
}
```

---

### 🏆 ผลงานและความสำเร็จ (Achievement)
วางสิ่งนี้ลงในรายการ `"achievements": [`:

```json
{
    "text": "อธิบายรางวัลหรือความสำเร็จของคุณที่นี่",
    "tags": ["international", "education"]
}
```
